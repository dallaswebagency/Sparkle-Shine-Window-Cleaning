# Sparkle & Shine Window Cleaning, homepage redesign

Standalone HTML homepage for calgarywindowclean.com.

- `index.html` is the full page (CSS and JS inline).
- `images/` holds the generated images. Filenames and aspect ratios are in `IMAGE-PROMPTS.md`.
- The logo, hero photo and owner photo currently load from the existing Webflow CDN. Download them into `images/` before the old site is retired.

Design by Dallas Web Agency.

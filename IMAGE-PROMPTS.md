# Image prompts for Google Flow (Sparkle & Shine Window Cleaning)

Save each file into the `images/` folder with the exact filename shown. Use the aspect ratio listed. Every prompt ends with the same style line so the set looks consistent.

Style line (already included below): natural daylight, realistic photograph, clean modern look, no text, no logos, no watermarks, no people's faces in focus.

## 1. images/before-window.jpg
Aspect ratio: **4:3** (must match image 2 exactly)

Realistic photograph of a large residential picture window in Calgary, Alberta, seen straight on from outside. The glass is very dirty: dusty film, water spots, streaks, dead insects and grime in the corners, dull and cloudy. Wooden window frame, a hint of a grey spring garden reflected faintly. Overcast daylight, shallow depth of field, centred composition, no text, no logos, no watermarks.

## 2. images/after-window.jpg
Aspect ratio: **4:3** (must match image 1 exactly)

The same large residential picture window and wooden frame, same camera angle, same framing and same lighting as the dirty version, but now perfectly clean and crystal clear. Streak-free glass with a bright reflection of blue sky, tall evergreen trees and distant Rocky Mountains. Fresh, sparkling, brilliant. Natural daylight, realistic photograph, no text, no logos, no watermarks.

Tip: generate image 1 first, then use it as the reference image in Flow when generating image 2 so the framing matches.
